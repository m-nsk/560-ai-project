\begin{enumerate}

\item What is the main goal of approximation algorithms?
\begin{enumerate}
\item[A] To find the optimal solution
\item[B] To find a solution close to optimal
\item[C] To reduce the running time
\item[D] To increase the memory usage
\end{enumerate}

\item What is the approximation ratio of an algorithm?
\begin{enumerate}
\item[A] The smallest $\alpha$ such that the algorithm is an $\alpha$-approximation algorithm
\item[B] The largest $\alpha$ such that the algorithm is an $\alpha$-approximation algorithm
\item[C] The average running time of the algorithm
\item[D] The worst-case running time of the algorithm
\end{enumerate}

\item What is the goal of the vertex cover problem?
\begin{enumerate}
\item[A] To find a minimum vertex cover
\item[B] To find a maximum independent set
\item[C] To find a minimum dominating set
\item[D] To find a maximum clique
\end{enumerate}

\item What is the algorithm for vertex cover?
\begin{enumerate}
\item[A] Add one endpoint of each edge to the solution
\item[B] Add both endpoints of each edge to the solution
\item[C] Use a greedy approach to select vertices
\item[D] Use a dynamic programming approach
\end{enumerate}

\item What is the approximation ratio of the vertex cover algorithm?
\begin{enumerate}
\item[A] 1
\item[B] 2
\item[C] 3
\item[D] 4
\end{enumerate}

\item What is the goal of the load balancing problem?
\begin{enumerate}
\item[A] To minimize the maximum load
\item[B] To maximize the minimum load
\item[C] To minimize the average load
\item[D] To maximize the total load
\end{enumerate}

\item What is the algorithm for load balancing?
\begin{enumerate}
\item[A] Assign each job to the machine with the smallest load
\item[B] Assign each job to the machine with the largest load
\item[C] Use a greedy approach to select machines
\item[D] What is the running time of the load balancing algorithm?
\begin{enumerate}
\item[A] O(n)
\item[B] O(n log n)
\item[C] O(n^2)
\item[D] O(m \cdot n)
\end{enumerate}

\end{enumerate}
