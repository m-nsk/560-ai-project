\item What is the main goal of approximation algorithms?

\item[A] To find the optimal solution
\item[B] To find a solution close to optimal
\item[C] To reduce the running time
\item[D] To increase the memory usage
\end{enumerate}

\item Which algorithm is used for vertex cover with an approximation guarantee of 2?
\begin{enumerate}
\item[A] Greedy algorithm
\item[B] Select an arbitrary edge and add both endpoints to the solution
\item[C] Dynamic programming
\item[D] Brute force
\end{enumerate}

\item What is the approximation guarantee of the greedy algorithm for load balancing?

\item[A] 2
\item[B] 3

\item What is the goal of the load balancing problem?
\begin{enumerate}
\item[A] To minimize the average load
\item[B] To minimize the maximum load
\item[C] To maximize the minimum load
\item[D] To maximize the average load
\end{enumerate}

\item Which algorithm is used for load balancing?
\begin{enumerate}
\item[A] Greedy algorithm
\item[B] Dynamic programming
\item[C] Brute force
\item[D] Greedy algorithm assigning jobs to machines with the smallest load
\end{enumerate}

\item What is the improved approximation guarantee for the load balancing algorithm?
\begin{enumerate}
\item[A] 2

\item[C] 3
\item[D] 4
\end{enumerate}

\item What is the definition of an $\alpha$-approximation algorithm?
\begin{enumerate}
\item[A] A polynomial-time algorithm that returns a solution within a factor $\alpha$ of optimal
\item[B] A polynomial-time algorithm that returns an optimal solution
\item[C] A polynomial-time algorithm that returns a solution within a factor $\frac{1}{\alpha}$ of optimal
\item[D] A polynomial-time algorithm that returns a solution within a factor $\alpha^2$ of optimal
\end{enumerate}

\item What is the name of the problem where we want to return a subset of vertices that covers all edges in a graph?
\begin{enumerate}
\item[A] Vertex cover
\item[B] Load balancing
\item[C] Scheduling
\item[D] Approximation algorithms
\end{enumerate}

\item What is the goal of the vertex cover problem?

\item[C] To find a subset of vertices that covers some edges
\item[D] To find a subset of edges that covers some vertices
\end{enumerate}
